# Michael Marko Sesay portfolio

A self-contained, responsive portfolio for Michael Marko Sesay, built with plain HTML, CSS, and JavaScript.

## Structure

- `index.html` — page markup
- `assets/css/styles.css` — responsive styling
- `assets/images/` — local profile and banner images
- `pages/` — dedicated Projects, Achievements, Testimonials, Publications, CV, and Contact pages

Open `index.html` in a browser to view the site.
